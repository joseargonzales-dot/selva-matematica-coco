# 🐊 La Selva Matemática de Coco

Videojuego educativo de matemáticas diseñado especialmente para **niños de 7 años** y optimizado para la tablet **Samsung Galaxy Tab S6 Lite (CPU Snapdragon, pantalla 10.4" y S-Pen)**.

## Cómo jugarlo en la Samsung Galaxy Tab S6 Lite

### Opción 1 (Más rápida — 100% sin internet)
1. Copia el archivo `index.html` a la carpeta **Descargas (Downloads)** de la tablet Samsung Galaxy Tab S6 Lite.
2. Ábrelo desde **Mis Archivos** con **Google Chrome** o **Samsung Internet**.
3. ¡Listo! Funciona **100% offline**, con sonido integrado, guardado automático del progreso y soporte táctil + S-Pen.

### Opción 2 (Como app instalada a pantalla completa en la tablet)
1. Sube esta carpeta (`selva-matematica-coco`) a cualquier alojamiento estático gratuito (por ejemplo, GitHub Pages o Netlify).
2. Abre el enlace en **Google Chrome** en la Samsung Galaxy Tab S6 Lite.
3. Toca el menú `⋮` → **"Agregar a pantalla de inicio" / "Instalar aplicación"**.
4. Aparecerá el ícono de **Coco el Cocodrilo** en la tablet y se abrirá a pantalla completa sin barras del navegador, funcionando incluso sin Wi-Fi gracias al Service Worker (`sw.js`).
